# Infrared Chronicle — research timelines

Static, self-contained interactive timelines from the IR & Chrome ART infrared-photography research project.

- `/` — **Infrared Chronicle 1910–2025** (Historical Timeline, 353 events)
- `/digital-era/` — **Infrared Chronicle II** (Digital Era Timeline, 1986–2026, 219 events)

Both pages share IR & Chrome ART's live site header/navigation (pulled from `irchrome.art`'s own CSS/JS so it stays in sync automatically) and default to the English UI.

Source data is maintained in the private research repo; these are published snapshots. Canonical (editable, crowdsourced feedback) versions also live as Claude artifacts — see project docs.

Published via GitHub Pages: https://irchrome.github.io/chronicle/
